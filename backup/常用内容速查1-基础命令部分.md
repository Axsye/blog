# 1. `ls -l` 权限字符串

示例：

```text
-rwxr-xr-x
```

一共 10 个字符：

```text
- | rwx | r-x | r-x
↑    ↑      ↑      ↑
类型 user  group  others
```

## 1.1 文件类型

**【必记】**

| 字符 | 英文 | 含义 |
|---|---|---|
| `-` | regular file | 普通文件 |
| `d` | directory | 目录 |
| `l` | symbolic link | 符号链接 |
| `c` | character device | 字符设备 |
| `b` | block device | 块设备 |
| `p` | pipe / named pipe | 管道 / 命名管道 |
| `s` | socket | 套接字 |

**【记忆方法】**

```text
d → directory
l → link
c → character
b → block
p → pipe
s → socket
```

除 `-` 外，基本都来自英文关键词首字母。

# 7. `r / w / x`

```text
r = read
w = write
x = execute
```

---

## 7.1 普通文件权限

```text
r → 读取文件内容
w → 修改文件内容
x → 执行文件
```

例如：

```text
-rwxr-xr-x
```

owner 拥有：

```text
read + write + execute
```

---

## 7.2 目录权限

目录上的 `r/w/x` 和普通文件不同。

**【必记】**

```text
r → 读取/枚举目录项
w → 修改目录项
x → search / traverse
    查找、进入、穿过目录
```

**【记忆方法】**

```text
r = 看
w = 改
x = 走
```

### `r`

可以知道目录里面有哪些名字。

```text
read directory entries
```

### `x`

可以：

- `cd` 进入目录
- 把目录作为路径的一部分继续访问
- 查找一个已经知道名字的目录项

### `w`

允许修改目录项，例如：

- 创建文件
- 删除文件
- 重命名文件
- 创建子目录
- 删除子目录

# 8. 文件权限 vs 父目录权限

**【必记】**

```text
修改文件内容 → 看文件本身的 w
删除文件     → 看父目录的 w + x
```

例如：

```text
dr-x------ project/
-rwxrwxrwx project/app
```

可以修改：

```text
project/app
```

但是不能删除它，因为父目录没有 `w`。

**【记忆方法】**

> 文件决定“能不能改里面的东西”；  
> 目录决定“能不能增删里面的名字”。

# 9. 数字权限

```text

```

# 10. `chmod` 符号模式

结构：

```text
对象 + 操作 + 权限
```

对象：

```text
u = user
g = group
o = others
a = all
```

操作：

```text
+ = add
- = remove
= = set
```

权限：

```text
r / w / x
```

示例：

```bash
chmod u+x myapp
chmod g-w myapp
chmod o+r file
chmod a-x myapp
chmod ug+rw file
chmod go-rwx myapp
```

# 11. Owner 与 Group

示例：

```text
-rwxr-x--- 1 alice developers ... myapp
             ↑       ↑
           owner    group
```

权限匹配逻辑：

```text
是 owner？
   ↓ 是
使用 user 权限

否则属于 group？
   ↓ 是
使用 group 权限

否则
使用 others 权限
```

三组权限不是累加关系。

# 14. `id` 命令

例如：



# 15. `usermod`

```text
usermod = user modify
```

给用户增加附加组：

```bash
sudo usermod -aG dialout alice
```

其中：

```text
-a = append
-G = supplementary Groups
```

**【必记】**

```text
-aG = append Groups
```

不要轻易写成：

```bash
usermod -G ...
```

因为可能覆盖用户原来的附加组。

例如：

```bash
sudo usermod -aG dialout $USER
```

常用于让 Ubuntu 普通用户访问串口设备。

修改组后通常需要：

```text
注销 → 重新登录
```

再通过：

```bash
id
```

确认。

# 16. 串口权限实例

例如：

```text
crw-rw---- 1 root dialout ... /dev/ttyUSB0
```

表示：

```text
类型   = character device
owner  = root
group  = dialout

user   = rw-
group  = rw-
others = ---
```

如果当前用户属于 `dialout`：

```text
使用 group 权限 → rw-
```

如果既不是 root，又不属于 dialout：

```text
使用 others → ---
```

# 32. `2>&1`

```bash
myapp > all.log 2>&1
```

表示：

```text
stdout → all.log
stderr → stdout 当前的位置 → all.log
```

最终：

```text
stdout ─┐
        ├→ all.log
stderr ─┘
```

**【记忆方法】**

```text
2>&1
→ 让 2 跟着 1 当前的位置走
```

---

# 33. 重定向顺序

Shell 从左到右处理重定向。

```bash
myapp > all.log 2>&1
```

最终：

```text
stdout → all.log
stderr → all.log
```

而：

```bash
myapp 2>&1 > all.log
```

处理过程：

```text
2>&1
stderr → stdout 当前的位置 → terminal

> all.log
stdout → all.log
```

最终：

```text
stdout → all.log
stderr → terminal
```

# 36. `grep`

`grep` 名字来源：

```text
g/re/p
≈ global regular expression print
```

核心作用：

> 搜索匹配内容，默认输出匹配内容所在的整行。

基础格式：

```bash

```

例如：

```bash

```

其中：

```text
uart       → pattern
kernel.log → file
```

# 37. `grep` 常见选项

## `-i`

```text
-i = ignore case
```

忽略大小写：


---

## `-n`

```text

```

显示行号：

## `-o`

```text

```

只输出匹配部分。



## `-v`

```text
-v = invert match
```

反向匹配：

```bash

```

输出不匹配 `error` 的行。

---

## `-r`

```text
-r = recursive
```

递归搜索文件内容：

```bash
grep -r uart .
```

注意：

> `grep` 搜索的是文件内容，不是文件名。

# 42. `find` 深度

## 最大深度

```text
-maxdepth N
= maximum depth
```

例如：

```bash
find . -maxdepth 1 -type f
```

只处理当前目录这一层。

---

## 最小深度

```text
-mindepth N
= minimum depth
```

例如：

```bash
find . -mindepth 2 -type f
```

只考虑 depth ≥ 2。

---

## 深度例子

```text
.               → depth 0
./file.txt      → depth 1
./src/main.c    → depth 2
./src/a/test.c  → depth 3
```

组合：

```bash
find . -mindepth 2 -maxdepth 3 -type f
```

表示：

```text
只匹配 depth 2 ～ 3
```

# 47. Linux 文件系统目录树初步认识

Linux 使用统一目录树：

```text
/
├── bin
├── boot
├── dev
├── etc
├── home
├── lib
├── proc
├── sys
├── tmp
├── usr
└── var
```

不像 Windows 常见的：

```text
C:\
D:\
```

Linux 所有文件系统最终都挂载到 `/` 这棵目录树中。

这对后续理解：

- SD Card
- eMMC
- NFS
- root filesystem
- mount
- Embedded Linux

非常重要。
